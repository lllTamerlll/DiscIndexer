# Disc Indexer — ваш помощник в управлении инвентарём Zenless Zone Zero

Disc Indexer помогает навести порядок в артефактах ZZZ: загрузить отсканированный инвентарь, отфильтровать диски и автоматически отметить кандидатов на распыление.

## Возможности
- Импорт инвентаря из сканера AdeptiScanner-ZZZ
- До 4 профилей с возможностью переименования
- Фильтры по сету, главной характеристике и дополнительным характеристикам
- Автоматическая отметка дисков на распыление по пресетам
- Сортировка по сету, а внутри сета — по слотам от 1 к 6

## Установка
1. Скачайте последнюю версию со страницы [Releases](https://github.com/lllTamerlll/DiscIndexer/releases/latest).
2. Распакуйте архив целиком.
3. Запустите `DiscIndexer.exe`.

## Что нужно перед началом использования
Сначала получите файл инвентаря:
1. Скачайте сканер артефактов из репозитория [AdeptiScanner-ZZZ](https://github.com/D1firehail/AdeptiScanner-ZZZ).
2. Просканируйте свой аккаунт.
3. Сохраните файл инвентаря в удобное место.

## Загрузка инвентаря
1. Откройте вкладку «Базы данных».
2. В нужном слоте профиля загрузите ранее сохранённый файл. При желании переименуйте профиль — так будет проще ориентироваться.
3. Перейдите на вкладку «Инвентарь» — там появятся все ваши диски.

## Фильтры
Для удобного просмотра доступны фильтры по:
- сету артефактов;
- главной характеристике;
- дополнительным характеристикам.

## Пресеты и авто-отметка
Сортировка и автоматическая отметка работают по четырём пресетам:

| Пресет         | Назначение                            |
| -------------- | ------------------------------------- |
| **Атакер**     | подсчёт пользы для агентов Атаки      |
| **Разрушатор** | подсчёт пользы для агентов Разрушения |
| **Аномалист**  | подсчёт пользы для агентов Аномалии   |
| **Общее**      | учитывает все три пресета сразу       |

Первые три пресета считают «пользу» дисков только для своей ниши.

Пресет **«Общее»** берёт в расчёт все три ниши и помечает на распыление только те диски, которые имеют наименьшие характеристики во всех трёх нишах одновременно. Такой подход менее агрессивен и помогает не выбросить лишнего.

Если же нужно провести строгую ревизию по одному конкретному пресету из основной тройки, отфильтруйте диски — например, выберите только те сеты, которые должны участвовать в подсчёте. Тогда остальные диски в расчёт не попадут.
